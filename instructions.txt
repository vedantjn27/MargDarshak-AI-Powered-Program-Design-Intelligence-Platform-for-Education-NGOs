MargDarshak instructions
========================

Use setup_guide.md for current local setup, environment variables, deployment,
and troubleshooting. README.md contains the short quick start and product flow.

The old direct-browser API setup and Node 18 instructions are no longer current.
The frontend uses its /api/proxy route and requires Node.js 20.9 or newer.
For the backend, use backend/.venv/Scripts/python.exe on Windows or
backend/.venv/bin/python on macOS/Linux for both pip and uvicorn.
