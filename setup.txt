MargDarshak setup
=================

The maintained setup and deployment instructions are in setup_guide.md.
Quick start: see README.md.

Requirements: Python 3.11 or 3.12, Node.js 20.9+, npm, and MongoDB.
Backend: create backend/.venv, install backend/requirements.txt with its Python,
then run uvicorn with that same interpreter after creating private backend/.env.
Frontend: run npm ci and npm run dev from frontend/.
Account flow: sign up at /auth, register an organization, then use the dashboard.
